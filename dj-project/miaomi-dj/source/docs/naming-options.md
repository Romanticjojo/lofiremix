# 命名建议

当前页面先使用中性名称 **DJ 试听室 / THE WEEKND · DJ SESSION**；不再展示 AFTER DARK 或 MIAOMI DJ。正式名称待用户选择；仓库和云端内部目录无需跟着改名。

我最推荐：产品 **接拍 · NEXTBEAT**，本期 **霓虹脉冲 · NEON PULSE**。

“接拍”直接表达衔接和下一拍，好记，也适合以后扩展到其他歌手。“霓虹脉冲”适合这期更紧凑、频繁切换的 The Weeknd 舞曲场景。
