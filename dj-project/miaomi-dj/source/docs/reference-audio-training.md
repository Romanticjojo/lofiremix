# 参考音轨训练与验收结论 · 2026-09-25

已完成真实训练并保存权重。**目前最值得继续试验的是六参数声学选曲模型；切点模型尚不适合自动控制播放。** 本次没有微调 GLM、Jev、LLM、Beat This! 或 Demucs，也没有把自动标签冒充真人好坏评价。

## 素材与数据

- 新增 `Creepin'`、`Cry For Me`，本地曲库共 25 首。25 首分析已刷新，文件改名通过内容哈希识别，旧音源未改写。
- Downloads 中 8 个 Weeknd MP4 已复制到 `reference_videos/20260925/`，原件保留；逐文件验证 SHA-256。每个目录含 `source.mp4`、完整双声道 48 kHz `audio.flac` 和 `source.json`。
- 实际音轨总长 **13,944.744 秒，约 3 小时 52 分 25 秒**。以实际时长为准，文件名中的“30min”等字样不是检测结果。
- 对 2,289 个窗口做录音匹配，989 个通过歌曲身份阈值与竞争曲目差值；连续性过滤得到 75 段可识别片段，形成 **30 条弱转场示范、22 种有向曲对**。
- 增加同曲重复段落的歧义过滤后，仅 **12 条**可进入出歌位置回归训练。未识别、缺原曲、短片段、定位歧义和未知效果保持未知。
- 最终数据：`outputs/reference-audio-20260925-v2/`。包含 JSONL、JSON Schema、每窗匹配分数、片段、时间区间、来源哈希、30 个参考转场 FLAC 摘录及 `REVIEW.md`。
- 模型和标准 messages 格式：`outputs/reference-audio-model-20260925-v3/`。每行 SFT 都有旁边的 provenance 索引；只是兼容格式导出，未运行 LLM 微调。

## 训练与测试

选曲：每次留出一整段视频，训练集删除与测试相同的有向曲对。650 参数曲序模型的正则强度只由内部视频划分挑选；全量模型由内部结果投票选定 L2=1、上下文 1 首。六参数声学模型使用速度差、调性距离、能量差与候选曲音频属性，固定 L2=1。它是在看到第一轮结果后追加的探索比较，不是新外部盲测。

下面为 **8 个视频等权平均**。每次从其余 24 首中选下一首；只评价是否与自动识别的参考曲序一致，不评价混音听感。多个合理选择可能被此指标算错。

| 方法 | 首选命中 Top 1 | 前三命中 Top 3 | MRR 越高越好 | 概率损失越低越好 |
|---|---:|---:|---:|---:|
| 六参数声学模型 | **19.20%** | 19.20% | **0.2950** | **3.1627** |
| 650 参数曲序模型 | 2.08% | **20.33%** | 0.1935 | 3.1929 |
| 训练集常见下一首 | 2.08% | 16.26% | 0.1805 | 3.5857 |
| 均匀随机 | 4.17% | 12.50% | 0.1573 | 3.1781 |

六参数模型实际命中 7/30 条，分布于 5 个视频；按条数统计是 23.33%，与上表按视频平均的 19.20% 口径不同。650 参数模型在训练数据上的 Top 3 为 53.33%，**不能把这个拟合成绩称为测试成绩**。早期 42 首标题的章节实验也不能与本次 25 首候选库直接横比。

本机 CPU 对六参数模型做 200 次预热后计时，单次选曲中位数约 **0.30 ms**、95 分位约 **0.64 ms**；这是已加载音频特征后的排序耗时，不包含读音频、分析和渲染。当前瓶颈是监督数据质量与覆盖，决策速度不是主要问题。

出歌位置：七参数岭回归，在留出视频的同时删除训练集中同一首出歌，避免记住某首歌的固定位置。12 条样本、7 个可评估视频，平均绝对误差 **64.84 秒**；训练集位置中位数基线为 **68.58 秒**。虽然略好于该基线，误差仍远超可用切点，**不接管切歌**。

## 录音对齐的独立检查

1. 第一批 25 个已知位置的原曲片段加入变速、变调、高通和音量变化，24 个通过歌曲匹配且身份正确，另一个拒识；25 个缺歌对照均拒识。
2. 发现 `Blinding Lights` 匹配到了另一遍相似副歌，位置错 56 秒。新增同曲竞争位置分数门控，复测该错误被拒绝：19 个片段通过位置门控，其中没有超过 3 秒的位置错误。
3. 不再改阈值，换到同一批录音中不重叠的另一组片段：25/25 歌曲身份正确，24 个通过位置门控，位置误差均为 0 秒；25 个缺歌对照仍全部拒识。

这是小规模、已知原曲的工程检验，不等于真实 DJ 叠歌窗口的人工标签准确率。自动边界区间通常仍有数秒至十多秒不确定性；没有从混合音轨恢复精确 EQ、推子、混响或人声动作。相关录音可能共享演出片段，整视频留出和曲对清除降低了重复信息影响，但不能据此宣称完全独立的泛化能力。

## 交付模型

| 文件 | 用途 | 当前判断 |
|---|---|---|
| `acoustic-model.json` | 六参数声学选曲权重、输入特征与曲库 | 推荐继续作小权重候选排序实验；未上线 |
| `choice-model.json` | 650 参数曲序示范模型 | 对照保存；首选结果较弱，未上线 |
| `cue-model.json` | 七参数出歌位置回归 | 已训练；误差过大，未上线 |
| `choice-splits.json` / `cue-splits.json` | 训练、测试和清除样本 ID | 可逐折复查 |
| `*-heldout-predictions.jsonl` | 逐条测试预测 | 可追溯结论 |
| `protocol.json` / `checksums.json` | 配置、输入和文件校验 | 可复现 |

未来推理时由可用曲目列表明确排除用户不想播放的歌曲；历史参考音轨中出现这些歌，不代表重新加入当前歌单。没有修改既有听评记录。30 条自动示范不是 30 对真人 A/B 偏好，不能据此宣称已满足个人偏好微调门槛。

## 复现

使用新的输出目录，已有结果不会覆盖：

```powershell
.venv\Scripts\python.exe scripts\prepare_reference_audio.py --library outputs\weeknd-library-20260925\library.json --manifest reference_videos\20260925\manifest.json --output outputs\new-reference-audio
.venv\Scripts\python.exe scripts\train_reference_audio.py --dataset outputs\new-reference-audio --output outputs\new-reference-model
.venv\Scripts\python.exe scripts\audit_reference_alignment.py --dataset outputs\new-reference-audio --output outputs\new-alignment-controls --offset-base 85
.venv\Scripts\python.exe scripts\export_reference_examples.py --dataset outputs\new-reference-audio
```

原始视频和音轨、特征、模型与数据集均留在本地且不进入 Git。在线播放器仍使用此前规则约束的候选方案渲染，未接入这三个新权重。下一步应优先补齐参考里缺失的原曲、审核高价值切点与真实 A/B 听评，优先解决正确标签，再扩大模型。
