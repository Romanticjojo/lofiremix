# DJ Agent 设计方案

日期：2026-09-23。用户已批准在 D:\DJ_agent 实施与测试。当前目标为家庭自动播放、混音录音、个人试听反馈，以及 Pioneer DDJ-200 联动；最终默认无人值守，可随时人工接管。

## 成功标准

1. 从真实 The Weeknd 本地歌曲构建可重复分析的曲库，生成有起伏的曲序和可解释过渡方案。
2. 自动完成切入切出、节拍/乐句对齐、有限变速、响度控制、EQ/滤波及克制效果，保存混音和每次决策。
3. 首轮目标是 20–30 分钟、至少 6 次真实曲目衔接；素材不足时如实记录未通过，不以合成音乐或循环短试听片段冒充。
4. 在同一歌曲组合上比较基线交叉淡化与增强过渡，提供试听 A/B 和客观报告。客观指标不等同于艺术质量，不宣称未经听评的“效果最好”。
5. 接入 Mixxx 与 DDJ-200；实际连接、消息回读、声音输出和手动接管必须分别验证，模拟测试不能替代实机验收。

## 已确认设备

Windows 11，Core Ultra 9 275HX，约 32 GB RAM，RTX 5080 Laptop 16 GB VRAM。Python 3.11 可用，FFmpeg 8.1 已安装。软件优先本地运行，暂不购买云服务。2026-09-23 扫描时未检测到 DDJ-200 PnP 设备；真实连接状态随时可能改变。

## 架构

本地曲库 -> 音乐分析缓存 -> 候选过渡 -> 约束检查与候选排序 -> 时间计划 -> 执行 -> 录音/事件/反馈。

- **分析层**：FFmpeg 解码；Beat This! 预训练节拍/小节检测优先，不可用时显式标记传统节拍回退；响度、调性、能量和音色特征；结构边界仅标为候选，避免伪称识别出副歌。保留检测置信度和人工修订入口。
- **计划层**：允许 4/8/16/32 小节候选过渡；限制变速幅度，考虑半拍/双拍速度解释；按段落/低冲突窗口、调性距离、能量目标和不重复播放排序。跨速度较大或低置信度采用保守过渡。
- **执行层**：本地确定性执行，禁止 LLM 直接按帧控制音频。先做离线渲染参考，再对接 Mixxx 实时控制；二者的功能覆盖和声音差异必须报告。
- **Mixxx 连接**：优先官方脚本/控制接口与本地桥接；先验证通信与状态读取，禁止声称存在未经证实的通用 REST API。控制器原有映射备份后扩展。模型失联不阻断已经准备的过渡。
- **模型层**：规则基线必须可独立运行；LLM 负责提前规划；Open-Jev/KEV 是可替换候选排序实验，不是已训练的 DJ。没有真实比较数据时不下载大模型或先做微调。
- **反馈层**：保存歌曲版本指纹、模型/分析版本、候选、参数、执行结果和试听标签。支持 A/B/相近/都不好，按歌曲组合隔离评测数据。

## 音频质量策略

先离线分析，避免分析与音频回调争抢资源。节拍与音频使用统一秒坐标。优先保留完整主要段落，限制人声密集片段长叠加。低频交接分开控制，预留输出余量，检查峰值与意外静音。滤波/回声/混响仅使用经过验证的模板，参数有上下界，不以频繁效果代替编排。

优先保留采样率一致的立体声渲染，使用保持音高的时间伸缩。每次转场导出前后上下文。针对相同歌曲组合保留普通淡化基线，防止复杂方案只是更响。

## DDJ-200

USB 连接 Mixxx；AI 自动控制的是软件参数。DDJ-200 无电动推子/旋钮，不会机械跟随；无内置音频接口，主输出来自电脑或外部声卡。接管时停止 AI 对相应控制的写入，并处理实体与软件位置差异。LED 仅承诺实测支持的状态。未连接设备时提供端口诊断和配置说明，不伪造硬件通过记录。

## 真实音乐与数据

用户提供可用于测试的本地 The Weeknd 音频路径。导入源文件只读，禁止覆盖/转移原文件；歌曲与权重不提交 Git。公开数据参考 Harmonix Set、M-DJCUE、djmix/transitions，先核对音频可用性与用途许可。未经允许不购买音乐、不绕过访问限制。

训练样本 = 状态特征 + 候选参数 + 渲染片段 + 客观指标 + 人类偏好 + 来源。技术缺陷可自动检测；审美优劣由少量真实试听确定。每轮 5–10 对，几十对先验证信号，再考虑小排序器和开源模型微调。训练/测试按曲目与组合分组，合成变体不当作独立歌曲样本。

## 异常与恢复

音频损坏/过短：拒绝并报告；下一首未装载：不启动过渡；模型超时：使用已校验候选；录音未启动：明显报错；错误 BPM/低置信度：降低变速与叠加复杂度；设备断开：播放继续、接管状态失效；人工接管：暂停 AI 写控制。所有计划在执行前检查路径、时长、越界和非有限数。
