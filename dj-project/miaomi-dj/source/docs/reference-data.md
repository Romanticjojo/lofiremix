合计 **61 条观察、42 个标题身份、57 个不同的有向相邻曲对**。大小写合并了 `I Feel It Coming` / `I feel it coming`、`Out Of Time` / `Out of Time`。页面少量明显拼写问题有显式别名表，原文保留在来源记录。标题身份尚未验证音频版本，不能视为所有曲目均为 The Weeknd 独唱或本地文件身份已审阅。

**已填的训练标签是“这段参考曲序下一首是什么”。** 其他候选是示范未选择的替代项，不是人工差评，也不声称只有参考答案才适合接歌。

## 文件格式

| 文件 | 用途 |
|---|---|
| `choice-dataset.jsonl` | 实际训练的逐行 choice 格式：context / candidates / label / provenance / unknown_labels |
| `dataset.schema.json` | JSON Schema 2020-12；除 schema 外，程序另查候选包含标签、排除上下文以及章节源一致性 |
| `catalog.json` | 稳定标题 ID、原始别名、本地标题匹配及未审阅状态 |
| `sft-messages.jsonl` | system / user / assistant 的 chat messages 格式，供后续语言模型实验；本轮没有训练 LLM |
| `sft-index.jsonl` | SFT 文件每行对应的原始 ID 与来源 |
| `splits.json` | 每折 train / test / purged 的原始样本 ID |
| `folds/<video-id>/` | 每折训练/测试 JSONL、对应 SFT 和只用该折训练数据拟合的模型 |
| `model.json` | 全量数据重拟合模型，普通 JSON 权重，无 pickle 执行内容 |
| `heldout-predictions.jsonl` | 61 条逐例留出预测、真实参考目标、Top 5、是否在训练中见过相关歌曲、各基线成绩 |
| `report.json`、`model-card.md` | 数值结果及能力边界 |
| `provenance/`、`environment.json`、`checksums.json` | 原始记录副本、实现/运行版本与文件 SHA-256 |

这是带明确 schema 的工程数据格式；不存在所有 DJ 模型通用的统一标签标准。SFT 和 choice 导出是同一批示范的两种表示，不应合并计成双倍样本。

## 训练与评测结果

输入为当前歌曲与最多两首历史歌曲。特征包含歌曲独热编码、历史衰减项和截距；固定 L2 正则 0.05，使用 SciPy L-BFGS-B，从零初始化。每个视频在训练中具有相同的总权重，避免 50 分钟视频仅凭长度主导模型。

评测轮流留出一个完整视频，并从其余训练数据清除测试中相同的有向相邻曲对。三折分别清除了 4、4、2 条重复曲对；测试标签没有用于调参。三折共享已知标题词表，歌曲也可共享，因此此处测试的是已知目录中的新曲序，**不是陌生歌曲泛化，也不是听感评分**。

| 按视频等权平均 | Top 1 | Top 3 | 平均倒数排名 MRR |
|---|---:|---:|---:|
| 学习模型 | 4.17% | 14.23% | 0.1535 |
| 训练集下一首频率基线 | 3.99% | 12.25% | 0.1396 |
| 均匀随机 | 2.55% | 7.65% | 0.1086 |

各视频模型 Top 3 分别为 10.0%（40 条）、7.69%（13 条）、25.0%（8 条）。有两折的 MRR 低于频率基线；宏平均优势主要来自最短视频。样本很少且相互相关，没有统计显著性或通用效果优势结论。完整按样本平均、各折成绩及概率损失都在 `report.json`。

全量模型 JSON 约 114 KB；本机 CPU 200 次推理中位约 0.107 ms、P95 约 0.237 ms（包含权重转成数组，不包含磁盘载入或音频分析）。数据量很小，训练本身约 0.13 秒；这不是大模型训练性能。

**权重已保存，状态为 `experimental_not_enabled`。** 当前成绩不足以替换已有播放规则。需要扩大独立参考和真人听评，再检验曲序选择是否改善混音。
