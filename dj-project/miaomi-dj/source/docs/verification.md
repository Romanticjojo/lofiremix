## 审查发现与修复

1. 转场文件覆盖源音乐、路径逃逸：输出必须为空；转场 ID 严格验证；整场产物先写到自有暂存目录再发布；已做原文件字节保持回归。
2. NaN 时间通过比较：计划时间和元数据在任何落盘前做有限数检查；回归验证无最终输出目录。
3. 节拍量化导致 118 BPM 被估为 120：使用多拍时间跨度估计，辅以实际转场窗口时长对齐。
4. 前一次局部变速未传递：每次过渡重新依据当前甲板速度计算下一首，三首连贯过渡回归通过。
5. Mixxx SysEx 入口错误：使用官方 `incomingData` 调度入口，模拟与其一致。
6. M3U8 可覆盖音乐：检查源路径冲突、排他创建，已有文件保留。
7. 人工接管未真正停止 Auto DJ、初始化未读取 Auto DJ：接管关闭实际控件并确认；初始化触发状态读取；失败时拒绝 AI 写入。
8. Windows PowerShell 5.1 把无 BOM 中文脚本误解码：入口脚本改为 ASCII；实际启动命令及回归测试已验证进入正常曲库检查，空目录退出码为 2。
